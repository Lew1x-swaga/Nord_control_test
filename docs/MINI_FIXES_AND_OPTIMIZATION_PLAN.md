# Оптимизация и QA (Nord Control)

## Реализовано

- Единая нормализация имён exe (`ProcessNameHelper`); пустой блоклист не опрашивает процессы.
- Захват JPEG: переиспользуемые буферы; на учителе декодирование JPEG вне UI-потока + `BitmapSource.Freeze()`.
- DPI `PerMonitorV2`, реакция на смену сетевого адреса, ротация логов (до 10 MB, 3 файла в `%LocalAppData%\NordControl\logs`).
- Стресс reconnect и бенчмарк JPEG в тестах; `.editorconfig`.
- Ручной QA: список окон Win32, отклонение WAN IP, тосты и звук у ученика, баннер надзора, «Снять всё» по блоклисту, диалог конфликта запуска/блокировки.

## Архитектурная справка

Ориентиры нагрузки ученика (не контракт протокола): покой < 0.1% CPU / < 35 MB; урок без стрима < 0.5% / < 45 MB; стрим 8–12 fps < 2.5% / < 60 MB, ~1.5–3 Мбит/с.

Ручной IP учителя остаётся запасным путём, если UDP broadcast режет изоляция Wi‑Fi.
