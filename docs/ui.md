# UI

Язык всех строк — русский. У ученика после Join крестик сворачивает плашку в трей.

## Учитель

Окно не полноэкранное обязательное.

- Заголовок: `Nord Control — учитель`
- Сверху: имя класса (поле), **крупный PIN**, кнопки «Начать класс» / «Завершить класс»
- Пока класс не начат: хаб выключен, PIN можно перегенерировать
- После старта: PIN не менять до «Завершить» (иначе ученики с старым PIN не войдут)
- Слева список учеников: отображаемое имя, hostname серым, статус
  - `онлайн`
  - `переподключение`
  - `нет` (таймаут / отключён)
- **Вид списка (этап 6):** переключатель «Лента» / «Сетка» над списком. Сетка — карточки тех же полей, **без** кадра экрана, несколько в ряд. Клик как по строке. Запоминать вид в `%LocalAppData%\NordControl\teacher-ui.json`
- **Группы (этап 7):** фильтр/метки групп у списка; создать / переименовать / распустить; назначить выбранных. Панель программ: «Запустить / блоклист» ещё и **группе**
- Клик по ученику выбирает его и включает JPEG-стрим (предыдущему — `stream_stop`)
- Справа при выбранном: кадр экрана, таблица окон/процессов (exe, PID, заголовок), активный exe
- Без выбора / после отключения: заглушка «выберите ученика»
- Панель программ: быстрый запуск («Запустить у выбранного» / «Запустить у всех» / с этапа 7 «у группы»), блоклист («Применить всем» / «Выбранному» / «Группе» / «Снять всё»), hints ученика («+ В быстрый запуск» / «+ В блоклист»)
- **Сообщение (этап 8):** поле текста + «Отправить выбранному / группе / всем». Не чат: нет ленты переписки
- **Сетка экранов (этап 9):** в зоне мониторинга опция плиток превью (мелкий JPEG). Это не сетка списка этапа 6. Клик по плитке = большой кадр выбранного
- Конфликт запуска и запрета одного exe — диалог подтверждения
- Статус бар: `класс запущен · порт 47821 · учеников: N`
- «Завершить класс» и закрытие окна: послать `session_end` всем, потом выйти

## Ученик

- Узкая плашка сверху экрана (всегда поверх при сессии / reconnect), не на весь рабочий стол
- Трей обязателен: `NotifyIcon` (`UseWindowsForms=true` в csproj ученика), пункты «статус», «покинуть урок…» и «выйти из программы…»
- Тексты плашки:
  - нет сессии: `Nord Control — ожидание класса`
  - онлайн: `Урок · учитель на связи`
  - переподключение: `Нет связи с учителем · переподключение…`
  - после явного конца: снова ожидание класса (повторный вход — руками, по PIN)
- Пока учитель смотрит экран — отдельный баннер надзора (`Nord Control — надзор`)
- Тост + короткий звук: запретили приложение; урок окончен / ограничения сняты. Тост блоклиста по-прежнему автоскрывается
- **Уведомление учителя (этап 8):** отдельное окно, не `ToastWindow`. Центр по горизонтали, чуть ниже верха. Свои цвета (не розовый тост запрета). Текст + крестик. Не закрывается само. Крестик только прячет уведомление. Звук при появлении — тот же короткий ding
- После Join крестик не завершает процесс и не рвёт сессию: плашка уходит в трей. Kill процесса — не блокируем средствами malware

PIN нужен только чтобы **войти** в класс (соседний кабинет). Выход ученика PIN не охраняет: он его уже знает. Пока урок идёт, крестик прячет плашку. «Покинуть урок» и «Выйти из программы» в трее спрашивают подтверждение; до Join окно закрывается сразу.

## Ошибки

Короткий текст, процесс жив: «неверный PIN», «класс не найден», «версия протокола не совпала», «порт занят — закройте второй Teacher».
