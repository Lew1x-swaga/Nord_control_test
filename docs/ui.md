# UI

Язык всех строк — русский. Закрывать крестиком = попытка выхода (у ученика — через PIN).

## Учитель

Окно не полноэкранное обязательное.

- Заголовок: `Nord Control — учитель`
- Сверху: имя класса (поле), **крупный PIN**, кнопки «Начать класс» / «Завершить класс»
- Пока класс не начат: хаб выключен, PIN можно перегенерировать
- После старта: PIN не менять до «Завершить» (иначе ученики с старым PIN не войдут)
- Слева список учеников: отображаемое имя, hostname серым, статус
  - `онлайн`
  - `переподключение`
  - `нет` (таймаут / отключён)
- Справа на этапе 1: заглушка «выберите ученика» / «экран появится на этапе 2»
- Статус бар: `класс запущен · порт 47821 · учеников: N`
- «Завершить класс» и закрытие окна: послать `session_end` всем, потом выйти

Выбор ученика кликом (этап 2 включает стрим). На этапе 1 клик только подсвечивает строку.

## Ученик

- Узкая плашка сверху экрана (всегда поверх при сессии надзора / reconnect), не на весь рабочий стол
- Трей обязателен: `NotifyIcon` (`UseWindowsForms=true` в csproj ученика), пункты «статус» и «выйти…» (PIN)
- Тексты плашки:
  - нет сессии: `Nord Control — ожидание класса`
  - онлайн: `Урок · учитель на связи`
  - переподключение: `Нет связи с учителем · переподключение…`
  - после явного конца: снова ожидание класса
- Закрытие плашки/окна без PIN запрещено. Kill процесса — не блокируем средствами malware

Пароль выхода = **PIN текущего класса**. Если сессии ещё не было — выход без PIN на этапе 1 допустим, чтобы не запереть агент до Join (иначе домашний тест неудобен). После успешного Join — выход только с PIN этого класса, пока процесс жив.

## Ошибки

Короткий текст, процесс жив: «неверный PIN», «класс не найден», «версия протокола не совпала», «порт занят — закройте второй Teacher».
