# Концепт Nord_control_concept

Статус: зафиксировано 2026-08-15, уточнено после ревью. Менять только явно, не «заодно».

## Зачем

Мини-софт для школ: у учителя и у учеников стоит приложение. Учитель **частично** управляет ПК ученика в рамках урока — смотрит, запускает учебное, запрещает отвлекающее. Продажа — школам и похожим кабинетам.

Первый рабочий контур: **ноут учителя ↔ ПК ученика**. Архитектура на класс (~20–30), тесты сначала 1:1 и loopback (два процесса на одной машине).

## Роли

| Роль | Где | Что делает |
|---|---|---|
| Учитель | Windows 10/11 x64 | Создаёт класс в LAN, видит список, экран выбранного, процессы; запускает и запрещает приложения |
| Ученик | Windows 10/11 x64 | Агент, плашка, трей. После Join выход из UI — PIN класса |
| Админ школы | позже | Тихая установка, GPO. В MVP отдельного кабинета нет |

ОС сейчас — только Windows. Android в перспективе: общий **протокол**, не общий UI.

## Что умеет продукт (ядро, этапы 1–3)

Этап 1: найти класс, войти по PIN, держать сессию, пережить обрыв LAN, явно отключить учителя.

Этап 2: живой экран выбранного ученика (без мыши/клавиатуры) + краткий список процессов.

Этап 3: открыть приложение из пресета (пресет + список установленного, утверждает учитель) + запрет exe (закрыть и не дать открыть), fail-open.

Подробно: [requirements.md](requirements.md), экраны: [ui.md](ui.md).

## Чего нет в v1

Удалённый рабочий стол, запись экрана, облако, чат, блок экрана/мыши, фильтр сайтов, микрофон, камера, кейлоггер, скрытый режим, лицензионные ключи, автозапуск после reboot, Android-клиент, TLS как обязательная часть ядра.

## Сессия

Агент работает, пока его запустили. Надзор и запреты — только пока сессия с учителем жива или в окне reconnect (120 с). Явный уход учителя снимает всё сразу.

MVP: после reboot агент **не автозапуск**. Для школы позже — служба; без учителя запретов всё равно нет.

## Наблюдение видно

Скрытый надзор — не этот продукт. Плашка + трей. Кадры не пишутся на диск и не уезжают с LAN.

Продуктовый контур под РФ (не юридическая консультация): живой просмотр на уроке, локально, явно, без архива. Школа — оператор ПДн.

## Учётные записи Windows

Ученик может быть админом. Kill в диспетчере → ПК в норме, учитель видит офлайн. Не делаем руткит. Жёсткий класс — ограниченная учётка / GPO, это инструкция школе.

## Имя и стек

Продукт: **Nord_control_concept**. Код: `NordControl.*`. UI русский. .NET 8, WPF. Бренд можно сменить позже.
