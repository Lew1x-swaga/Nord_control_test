# Инварианты

Нарушать нельзя ни в «временном» коде, ни «чтобы заработало на моей машине».

## 1. Fail-open

Ограничения только в памяти агента. Нет AppLocker, WFP, вечных ключей реестра, hosts, драйверов фильтрации.

ПК ученика обычный, если: явный `session_end`; 120 с без данных от учителя; процесс агента убит; reboot без автозапуска; приложение удалено.

`launch_app` — разовый старт, не хук.

## 2. Интернет не условие жизни

Heartbeat / discovery / кадры — только LAN. Не пинговать 8.8.8.8, не ходить в облако, не выходить из процесса из‑за «нет интернета».

Школьный шлюз может лежать — кабинет работает, если LAN жива. Обрыв LAN не делает `Environment.Exit`.

## 3. Явный уход ≠ моргнувшая сеть

| Событие | Поведение |
|---|---|
| Кнопка «завершить» / штатное закрытие Teacher | `session_end`, fail-open сразу |
| Нет сообщений ≥10 с | Пауза стрима, процессы живы |
| Нет сообщений ≥120 с | Fail-open, ожидание нового класса |
| TCP drop при lastRecv < 120 с | `Reconnecting`, запреты держать, exe живы |
| Kill Teacher без `session_end` | Как обрыв: reconnect, затем fail-open по таймеру |

## 4. Один видеопоток

Стримит только выбранный ученик.

## 5. Надзор видимый

Плашка + трей. Не маскировать процесс, не кейлоггер, не писать экран на диск.

## 6. Протокол без Win32-типов

В `NordControl.Protocol` нет `HWND`, `HMONITOR`. Путь запуска — опциональная строка `launch_target`.

## 7. Запрет по exe

Имя файла, OrdinalIgnoreCase. Не резать по заголовку окна как основной ключ. Не убивать свои процессы.

## 8. Не обходить защиту ОС

Пароль (PIN) на выход из UI — да. Служба автозапуска — после этапа 3. Скрытое удержание против админа, прятки из диспетчера, парные «сторожа» — нет.

## 9. Сначала этап 1

Пока связь 1:1 не принята по `requirements.md` (сценарии 1–7), не делать DXGI, JPEG, пресет, блоклист, установщик, Android.
